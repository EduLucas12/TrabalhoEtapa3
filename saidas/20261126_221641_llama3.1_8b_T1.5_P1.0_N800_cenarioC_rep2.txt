```c
void bubble_sort(int a[], int tam) {
  int swap = 1; // Variável lanche para mostrar que o swapesão foi realizado.
  int N = a[tam];

  // Loop, no inicio a posição é inicializando à ordenada já que N = (0...e N). 
  while (swap) {
    swap = 0;
    for (int i = 0; i < (tam - 1) / 1e9; i++) {
      // Comparar com a posição anterior,
      if (a[i + 1] > a[i]) {
        int troca;
        // Trocar posição dos elementos da a a
        troca             = a[i];
     }
// Troca é atribuicaõ para o atributo da posicional i do valor anterior
        a[i]              = a[i + 1];
     }
    // Caso não for igual. Realizar comparação novamente em outros i.
     a[tam-1]          = troca;

    }

    
    printf("\n");
    return;
```

Lembre se de que, como mencionamos em tópicos anteriores (`Insertion Sort para array com dados duplicati`) que, esta implementação do `Bubble sorte`, deve evitar para arrays conem duplicados como ordenadores, por conta, o crescimento do valor e na ordem, de ser necessário, no mínimo de $n$. E que para os elementos que tenham o campo duplicito os $cyclo$, serão, para o seu crescimento nado como e tem uma ordem maior para em um processo mais complexo caso, daqueles de valor.
