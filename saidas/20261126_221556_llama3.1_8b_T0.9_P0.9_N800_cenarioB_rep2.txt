**Bubble Sort em C**
=====================

O Bubble Sort é um algoritmo de ordenação simples que compara iterativamente cada par de elementos e troca-os se necessário. Aqui está a implementação em C:
```c
#include <stdio.h>

/**
 * Função de ordenação Bubble Sort.
 *
 * @param array   Ponteiro para o array a ser ordenado.
 * @param tamanho Tamanho do array.
 */
void bubbleSort(int *array, int tamanho) {
    int i, j;
    int troca;

    // Iterações necessárias para garantir que o array está ordenado
    for (i = 0; i < tamanho - 1; i++) {
        // Suponha que o array está ordenado até a posição i
        troca = 0;

        // Compare cada par de elementos e troque-os se necessário
        for (j = 0; j < tamanho - i - 1; j++) {
            if (array[j] > array[j + 1]) {
                // Troque os elementos
                int temp = array[j];
                array[j] = array[j + 1];
                array[j + 1] = temp;
                troca = 1;
            }
        }

        // Se nenhuma troca foi feita na iteração atual, o array já está ordenado
        if (troca == 0) {
            break;
        }
    }
}

/**
 * Exemplo de uso da função bubbleSort.
 */
int main() {
    int array[] = {64, 34, 25, 12, 22, 11, 90};
    int tamanho = sizeof(array) / sizeof(array[0]);

    printf("Array antes da ordenação: ");
    for (int i = 0; i < tamanho; i++) {
        printf("%d ", array[i]);
    }
    printf("\n");

    bubbleSort(array, tamanho);

    printf("Array após a ordenação: ");
    for (int i = 0; i < tamanho; i++) {
        printf("%d ", array[i]);
    }
    printf("\n");

    return 0;
}
```
**Explicação**

A função `bubbleSort` toma como entrada um array de inteiros e seu tamanho. Ela iterará sobre o array `tamanho - 1` vezes, comparando cada par de elementos e trocando-os se necessário. A variável `troca` é usada para verificar se houve trocas na iteração atual; se não houve, o array já está ordenado.

O exemplo de uso demonstra como chamar a função `bubbleSort` e imprimir o array antes e após a ordenação.

**Complexidade**

*   Tempo: O tempo de execução do Bubble Sort é O(n^2) no pior caso, onde n é o tamanho do array.
*   Espaço: O Bubble Sort necessita de espaço extra para o temporário usado nas trocas, portanto sua complexidade de espaço é O(1).

**Observações**

*   O Bubble Sort é um algoritmo simples e fácil de entender, mas pode não ser a escolha mais eficiente para grandes conjuntos de dados.
*   O Bubble Sort é estável, pois não altera a ordem relativa dos elementos iguais.
